## 1. 项目定位

macOS 14+ 原生专用浏览器：WKWebView 渲染、AppKit 程序化界面、原生工具风。
最高优先级为内存管控：动态实例按真实进程内存执行 1GB 预算，超限时非阻塞提示；
静态收藏以 Markdown 本机缓存展示，不保留常驻 WebView。

- 语言/构建：Swift 6.4.1（Swift 5 语言模式）、SwiftPM，无 Xcode 工程
- 目标平台：macOS 14.0+（Intel 开发环境已验证）
- 分发：`scripts/build-app.sh` 生成 `dist/Membrow.app`
- 数据目录：`~/Library/Application Support/com.membrow.app`（旧目录 `Application Support/Membrow` 首次启动自动迁移）
- 工程规则：[AGENTS.md](../AGENTS.md)

## 3. 已实现能力

### 3.1 收藏与分组（T002、T005–T008）

- 收藏以稳定 UUID 标识，名称、入口 URL、类型、最后地址、代理、拦截、抓取配置全部持久化。
- 单层分组：数据层与 UI 均禁止嵌套；展开状态持久化。
- 拖拽排序、拖入/拖出分组、拖入 Pane；非法嵌套被拒绝且不落盘。
- 右键菜单：编辑、重命名、删除、复制链接、关闭网页、从入口重新打开（按 ID 定位）。

### 3.2 聚合与 Pane（T011–T015）

- 多聚合独立持久化，Pane 可水平/竖直连续分割，布局树持久化。
- 选中 pane：点击 pane 内任意位置（含页面内容）即聚焦，边框高亮；本地鼠标监听兜底 WKWebView 吃点击的问题，
  聚焦后同步视图快照再刷新边框，切分/放大/关闭作用于当前 pane。
- 收藏按 ID 拖入或替换 pane；拖入/显式打开即把该收藏的 WebView 搬进当前 pane（复用实例），原位置显示“已在别处打开”并可移回；仅当两个容器同时可见时，非持有方才显示占位。
- 放大/还原、关闭 pane（仅移除容器）、空聚合仍可分割与拖放；放大时隐藏的 pane 仍属于当前聚合面板，其收藏与快照一并豁免回收。
- 分割时保留原 pane 绑定的收藏。
- 聚合头部“打开全部网页”：逐 pane 复用或创建实例（已在别处显示的按复用规则搬入本 pane），隐藏 pane 也一并加载；静态收藏不走该操作，无动态 pane 时按钮隐藏。

### 3.3 动态浏览与导航（T016–T021）

- 每收藏最多一个动态实例，独立视图与 pane 间移动复用；切到聚合（原容器已不可见）时由可见 pane 自动接管实例。
- 原生前进/后退/刷新；导航完成持久化最后地址。
- 关闭网页销毁实例但保留收藏、配置和共享登录态；重开加载最后地址。
- 「从入口重新打开」：有实例时加载入口 URL，无实例时先创建实例再加载。
- 同站链接/同站新窗口留在当前 pane；跨站交给系统默认浏览器。
- 启动策略：不恢复（默认）、继续上次、打开指定收藏；启动不自动抓取静态收藏。

### 3.4 代理（T009、T010）

- 直连 / 系统代理 / 自定义 HTTP 代理三种模式，全局默认直连。
- 收藏级覆盖按 ID 持久化，未配置继承全局；清除覆盖恢复继承。
- 按代理派生 `WKWebsiteDataStore(forIdentifier:)`，不同代理的同 URL 收藏互不影响登录态。
- 地址与端口非法时不能保存为有效配置。

### 3.5 内存管控（T022–T026）

- `_webProcessIdentifier` + `proc_pid_rusage(ri_phys_footprint)` 采样 WebContent 与 Networking，
  不含 GPU/显存；`--diagnose-memory` 输出可复现报告。
- 精确模式：动态池 1GB 预算，不设实例数上限。
- 降级模式：私有接口失效（可故障注入）或采样失败时，使用可配置实例上限 + 系统内存压力。
- 激活中的动态实例与固定实例豁免；其余按最后可见时间 LRU；固定计入预算。
  “激活”＝实例的 WebView 仍在窗口层级且未被隐藏，不看遮挡状态，应用退到后台也不回收。
  当前聚合面板内所有 pane（含放大时被隐藏的 pane）一律视为前台激活，成对豁免动态实例与静态快照。
- 超限且无可淘汰对象：非阻塞横幅按占用排序列出实例，提供“关闭”快速操作。

### 3.6 内容拦截（T027）

- 仅使用 `WKContentRuleList`，规则存储位于应用数据目录，启动时编译挂载。
- 单收藏可关闭；切换只更新配置，已打开页面不变，刷新时按最新配置重新挂载。
- 编辑器提示“切换只更新配置，已打开的网页刷新后生效”。
- 规则集拆分为无析取条目（WKContentRuleList 不支持 `|` 析取）。

### 3.7 静态收藏（T028–T036）

- 按收藏 ID 的 SQLite 缓存：Markdown 正文、元信息、抓取时间分离存储。
- TTL：继承全局（默认 24h）、0 不用缓存、永不过期；支持分钟覆盖。
- 抓取：默认临时 WebView 完整加载（`didFinish` 后等正文出现且 DOM 稳定，最多 5s，再等待选择器、
  总超时 15s、使用共享登录态与收藏代理）；可选 HTTP 抓取（不执行 JS、携带同域 Cookie）。
- 提取：整页转换为默认实现（无需选择器，按原布局把 `<body>` 全量转 Markdown，仅丢弃脚本/样式/表单控件）；
  块级元素相邻成段、行内文本与元素之间补空格，段落内句子不拆散；
  CSS 选择器与通用正文提取均需收藏明确选择，失败不级联。
- 视图：新鲜直接展示；过期先显示旧内容 + “更新中”；失败保留旧缓存并报错；
  强制刷新绕过缓存；“使用原网页”创建临时动态实例，收藏类型不变。
- 展示方式（`StaticConfig.displayMode`）：**精简快照**（默认）在抓取时清洗 HTML（去脚本/事件/iframe/表单/预加载与隐藏节点，
  保留样式表）并存 `snapshot_html` 列，用禁用 JS 的非持久化 WebView 渲染，保留原布局；**Markdown 正文**保留原有转换实现。
  快照缺失时自动补抓，抓取期间回退显示 Markdown。
- 诊断输出：`--diagnose-memory` 用 `TextTable` 排成等宽表格（全角按 2 列宽）；
  设置窗口用 `SimpleTable`/`DiagnosticsTablesView` 展示真正的表格控件（概览 / 实例 / 配置三张表，可滚动）。
- 常驻巡检：`MemoryMonitor` 单次 Timer 按状态重排（无实例 30s / 超限或有淘汰动作 2s / 其余 5s，带 tolerance 合并唤醒），
  设置面板打开时随巡检自动刷新诊断表格，空闲时 CPU 占用为 0。
- 静态并发默认 2、硬上限 4，抓取任务独立预算、不进入动态 LRU；
  精简快照的常驻 WebView 通过 `SnapshotRegistry` 计入内存监控，与动态实例同池按 LRU 淘汰，
  被回收时该 pane 回退显示已缓存的 Markdown。

### 3.8 记住密码（2026-11-17）

- 动态实例注入 `CredentialScript.capture`：仅在表单 `submit` 时读取一次用户名/密码，经 `WKScriptMessageHandler` 回传；
  静态抓取的临时 WebView 不注入。
- 保存前必须用户确认（非阻塞 sheet）；相同凭据不重复提示；取消不写入。
- 存储只用钥匙串（`kSecClassInternetPassword` + `WhenUnlockedThisDeviceOnly`），密码不落 JSON / SQLite / 日志。
- 导航完成后若页面存在空密码框，自动填入该主机最近保存的凭据（触发 `input`/`change`），不覆盖用户已输入内容。
- 设置内“已保存密码”可查看、单条删除、全部清除。

### 3.9 侧栏与内存预算（2026-11-17）

- 侧栏可通过“显示 → 显示/隐藏侧栏”（⌃⌘S）折叠与恢复，折叠状态沿用 split view 自动保存。
- 动态池预算可配置：`AppSettings.memoryBudgetMB`，默认 1024（1GB），范围 128–8192；精确模式按该值计算超限。
- `AppSettings` 逐字段 `decodeIfPresent`，新增字段不会让旧 `settings.json` 整份失效。
- 设置窗口为非浮动普通窗口（`hidesOnDeactivate = false`），应用切到后台不会消失；每次打开重新读取设置与凭据。

### 3.10 站点图标与标题自动提取（2026-11-17）

- 收藏只需填 URL 即可保存：名称为空时以主机名占位，随后自动补全。
- `SiteInfoService` 用 `URLSession` 抓首页 HTML（不建 WebView、不注入脚本）：`<title>`/`h1` → `Bookmark.siteTitle`；
  图标取 `<link rel="icon">`，回退 `/favicon.ico`，统一转 PNG 存 `<数据目录>/site-icons/<收藏ID>.png`。
- 左栏与详情标题统一用 `Bookmark.displayTitle`（站点标题优先）；用户重命名后清空 `siteTitle`，自定义名称不被覆盖。
- 图标每次刷新都重新抓取（启动、创建/编辑收藏后）；标题仅在缺失时抓；删除收藏后启动时清理孤立图标文件。

### 3.11 应用图标（2026-11-17）

- `scripts/make-icon.py` 用标准库 + 系统 `sips`/`iconutil` 生成图标（SDF 解析抗锯齿，1024 设计稿），产物 `assets/AppIcon.icns` 入库。
- 视觉：Big Sur 圆角底 + 冷色渐变；前景三层堆叠页面卡（多会话同存），顶层卡片内为内存条状内容行。
- `scripts/build-app.sh` 拷贝 `assets/AppIcon.icns` 到 `Contents/Resources/`，Info.plist 设 `CFBundleIconFile=AppIcon`。
- 改图只改脚本里的设计稿常量后重跑：`python3 scripts/make-icon.py assets/AppIcon.icns /tmp/icon.png`（第二参数可选，另存 1024 PNG 供人工复验）。

### 3.12 网页麦克风与内存横幅口径（2026-11-18）

- 麦克风：`WebViewHandler` 实现 `webView(_:requestMediaCapturePermissionFor:initiatedByFrame:type:decisionHandler:)`——此前没有该回调，`getUserMedia` 直接拿到 `NotAllowedError`。
- 行为按设置项 `AppSettings.microphoneEnabled`（默认开）：允许时对该站点直接 `grant`，刷新/重开都不再追问；禁止时 `deny`。摄像头等其它采集类型仍一律拒绝。
- “这台机器能不能录”由系统隐私授权（TCC）把关，首次会弹一次系统对话框，之后按系统设置记忆。
- 该记忆绑定代码签名：ad-hoc（`codesign --sign -`）的 designated requirement 只有 cdhash，每次重建都会失效、导致每次都重新弹窗。`scripts/build-app.sh` 现在改用本地自签名身份 `Membrow Local Signing`（`scripts/ensure-sign-identity.sh` 一次性创建，`MEMBROW_SIGN_IDENTITY` 可覆盖），requirement 变成 `identifier "com.membrow.app" and certificate leaf = H"…"`，跨构建稳定。
- `Info.plist` 增加 `NSMicrophoneUsageDescription`（缺了它系统会直接杀进程）；设置窗口“媒体”行可开关，`--diagnose-memory` 与设置诊断表都会显示当前取值。
- 内存横幅只提示“固定页面”超限：`overageItems` 新增 `isVisible`，`updateMemoryBanner()` 过滤掉正显示在屏幕上的实例。可见页面本来就不参与回收，弹提示只会让人去关他正在用的那一页。
- 除横幅提示外，没有任何针对当前页面的限制行为（不阻止加载、不降级渲染）。

### 3.13 页面强制深色（2026-11-19）

- 收藏级配置：编辑收藏窗口新增“页面外观”下拉（`PageAppearance.system` = “页面默认”，`PageAppearance.dark` = “深色模式”）；取值存放在 `DynamicConfig.pageAppearance`，**默认与旧数据缺字段均按“深色模式”处理**（显式选择“页面默认”会写入 `system`）。
- 实现方式：`darkAqua` 让 WebKit 把 `prefers-color-scheme` 判为 dark；同时通过私有 `_addUserStyleSheet:` 注入纯 CSS（`ForcedDarkStyleSheet`），对没有深色样式的站点整体 `invert(1) hue-rotate(180deg)` 强制变暗。`img/video/picture/canvas` 反回去保持原色，内联 SVG 跟随反色（避免黑色图标消失）；样式表注入全部 frame。不执行 JS、不改写 DOM。
- 已知代价：会深色的站点也会被反转成浅色；`html` 上的 filter 会改变 fixed 元素的包含块，少数页面可能布局偏移；CSS 背景图/彩色 SVG 可能变色。私有接口不可用时降级为不反色，`--diagnose-memory` 显示“强制深色样式表”是否可用。
- 生效范围：动态收藏的网页实例与静态收藏均可用；创建/激活时应用，保存收藏后立即加/移除样式表，无需刷新。静态收藏的快照 WebView 同样注入反色，Markdown 视图按强制外观重新着色。
- `MembrowSelfTest` 覆盖展示名、旧收藏缺字段回退、显式深色保留与强制深色 CSS 关键规则。

### 3.14 开机自启（2026-11-20）

- 设置窗口新增“启动”行：`开机自启（登录时自动打开 Membrow）`；保存时用 `SMAppService.mainApp` 注册/注销系统登录项（`Sources/Membrow/App/LaunchAtLogin.swift`），不引入 helper app 或 LaunchAgent。
- 勾选状态以系统实际状态（`SMAppService.mainApp.status`）为准：用户之后在“系统设置 › 通用 › 登录项”里手动关闭，界面会跟着显示为关闭。
- 注册失败（未安装到 `/Applications`、签名不稳定）或需要人工批准时，错误/提示留在设置窗口，不静默失败。
- `AppSettings.launchAtLogin` 只是意向值的镜像，逐字段 `decodeIfPresent`，旧 `settings.json` 缺字段回退 `false`；`--diagnose-memory` 与设置诊断表都显示登录项实际状态。
- 生效前提：应用需位于 `/Applications` 且签名稳定（`scripts/build-app.sh` 默认使用本地自签名身份）。

### 3.15 开发者模式与诊断日志（2026-11-21）

- 设置窗口新增“开发者”行：`开发者模式（网页右键可“检查元素”）` 复选框 + `打开日志` 按钮。开关存放在 `AppSettings.developerMode`（默认 `false`，逐字段 `decodeIfPresent`，旧 `settings.json` 缺字段回退关闭）。
- 开启后动态实例的 `WKWebView.isInspectable = true`，网页右键出现“检查元素”，可打开 Web Inspector 看 Console / Network / DOM；保存设置时对已打开实例立即生效，无需刷新。关闭后立即失效。该开关只影响调试入口，不注入任何脚本。
- 诊断日志由 `MembrowCore/Services/DiagnosticLog.swift` 统一收集，写入数据目录的 `logs/`：
  - `info.jsonl`：应用启动、页面开始加载、加载完成（含耗时 `ms`）、关闭/回收实例。
  - `problems.jsonl`：`warn` 与 `error` 合并在一个文件——HTTP 4xx 记 `warn`，5xx、导航失败（`domain` / `code` / 描述）、WebContent 进程终止、数据读取告警记 `error`。
  - 行格式为单行 JSON（`ts / level / category / message / fields`），可直接用 `grep` 或 `jq` 过滤。
  - 单文件上限 20MB，超过后把当前文件改名为 `<文件名>.1`（只保留一份归档）并新建空文件；写入在串行后台队列，写盘失败静默丢弃，不影响页面。
- 隐私边界：日志里的 URL 去掉 query 与 fragment（避免令牌、会话 ID 落盘）；凭据、表单值一律不写入。
- `--diagnose-memory` 与设置诊断表显示“开发者模式”状态与 `logs/info.jsonl` 路径。
- 已知限制：不注入 JS，因此页面内部脚本报错、资源 404 不在日志范围内（HTTP 状态与导航失败可以）；需要看脚本错误时用开发者模式打开 Web Inspector。
- `MembrowSelfTest` 覆盖 info 与 warn/error 分行、JSON 字段结构、超限轮转（用小上限模拟）与旧配置缺字段回退。

## 4. 本轮修复摘要

| 问题 | 修复 |
| --- | --- |
| 关闭网页后「从入口重新打开」无效 | `BrowserRuntime.openFromEntry(bookmarkID:in:)`，无实例时创建并加载入口 |
| 同一收藏拖回 pane 不重开 | 拖入后清除终止态并刷新 slot |
| 侧栏/详情在无实例时无法从入口打开 | 菜单项常驻；详情按钮对动态收藏始终可用 |
| HTTP 页面被 ATS 拦截 | Info.plist 增加 `NSAllowsArbitraryLoadsInWebContent`、`NSAllowsLocalNetworking` |
| 拦截开关刷新后不生效 | `reload` 前按最新配置重新挂载规则 |
| 分割 pane 丢失原收藏 | `PaneNode.splittingPane` 保留原 bookmarkID（已补自测） |
| 启动时静态收藏自动抓取 | 启动路径 `allowStaticCapture=false`；修复侧栏选择恢复时序 |
