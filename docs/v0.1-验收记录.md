## 3. 关键实测记录

### 3.1 构建与自测

```
swift build                    # Build complete
.build/debug/MembrowSelfTest   # PASS 96 checks
./scripts/build-app.sh         # ad-hoc 签名 + codesign --verify --deep --strict 通过
```

### 3.2 关闭网页后的重开

1. Pane 右键 →「关闭网页」：pane 显示“已关闭”，侧栏“已关闭 · 动态”。
2. Pane 右键 →「从入口重新打开」：恢复网页，侧栏“运行中 · 动态”。
3. Pane 占位「重新载入」：恢复最后地址。
4. 侧栏右键「从入口重新打开」在无实例时也会先创建实例再加载入口 URL。

### 3.3 代理（T009/T010）

本地测试代理监听 `127.0.0.1:8898` 并记录请求：

- 全局自定义代理 + HTTPS 收藏：代理日志出现 `CONNECT example.com:443`。
- 同 URL 两收藏：ProxyA（自定义代理）产生 `CONNECT`；DirectB（直连）无代理请求并正常加载页面。

限制：WKWebView 的 `proxyConfigurations`（`httpCONNECTProxy`）在本环境只对 HTTPS 发起 CONNECT，
`http://` 请求仍直连；需求未区分协议，故记录为平台限制，未伪造代理生效。

### 3.4 内容拦截（T027）

本地页面 `block.html` 引用：

```
/ok.js /analytics.js /adsbygoogle.js /logo.png /tracker.gif?utm_source=test /ad.png?ad_id=1
```

| 拦截开关 | 服务端收到的请求 |
| --- | --- |
| 开启 | `block.html`、`ok.js`、`logo.png` |
| 关闭 | 上述全部（含 analytics/adsbygoogle/tracker/ad） |

切换开关后当前页面不变；刷新时按最新配置重新挂载规则（`BrowserRuntime.reload` 同步 `blockingEnabled`）。

### 3.5 内存超限（T026）

设置 `forceMemoryAPIFailure=true`、降级实例上限 1，打开两个可见动态 pane：

- 横幅：“内存超限：动态池超过预算，但有可见或固定实例不可回收，Mem-A（x MB），Mem-B（y MB）”。
- 点击“关闭 Mem-A”：Mem-A 立即关闭，实例数回到 1，横幅消失。
- 全程 WebView 未被强制回收，浏览未中断。

### 3.6 同站/跨站链接（T020）

本地页面 `page1.html`（127.0.0.1:8123）点击 `target="_blank"` 同站链接：应用内跳转 `/same.html`。
在 `same.html` 点击跨站 `https://example.org/`：前台应用变为 Chrome，Membrow 内未新建 WebView。

## 4. 已知限制与未决事项

1. **T037 公证阻塞**：无 Developer ID Application 证书，无法完成签名/公证与净机安装验证。
   当前 `dist/Membrow.app` 为 ad-hoc 签名，本机可启动；`codesign --verify --deep --strict` 通过。
   需提供证书（及 Apple ID 公证凭据）后重新执行 `scripts/build-app.sh` 并公证。
2. **沙盒测试环境**：外层沙盒下 `~/Library/WebKit` 写入受限，`WKWebsiteDataStore(forIdentifier:)`
   可能报 “could not create directory … for future sandbox extension”。正式运行（非沙盒）不受影响；
   代理与拦截实测均在未沙盒进程下完成。
3. **HTTP 代理**：见 §3.3，`http://` 不经过 CONNECT 代理。
4. **内存精度**：收藏级数值来自 WebContent 进程 `ri_phys_footprint`，不含 GPU/显存；
   进程共享场景已在 `--diagnose-memory` 报告中记录。
5. **干净用户环境安装**：受 T037 阻塞，尚未执行。
